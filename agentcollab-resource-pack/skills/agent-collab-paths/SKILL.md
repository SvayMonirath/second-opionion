# /agent-collab-paths — Alternative Solution Exploration

## Purpose

Discover genuine alternatives, compare their trade-offs and identify which is best supported by the user's requirements. This is not merely listing different analytical perspectives.

## Workflow

1. Define the problem, constraints and must-have requirements.
2. Identify the decision dimensions that meaningfully distinguish solutions.
3. Generate a small set of materially different and plausible approaches.
4. Explain each approach's operating model, dependencies and consequences.
5. Check feasibility against the actual environment and evidence.
6. Challenge each approach, including the leading option.
7. Compare using explicit criteria established before scoring.
8. Recommend one option, a conditional choice or further evidence needed.

## Quality rules

- Do not generate cosmetic variations of the same idea and call them separate paths.
- Do not invent options that violate hard constraints without clearly labeling them infeasible.
- Do not use arbitrary weighted numbers or false precision.
- Include switching cost, reversibility, complexity, risk and maintenance where relevant.
- Preserve conditions under which a non-leading option may be better.

## Report

Present each viable path, meaningful differences, trade-offs, requirements fit, evidence status, key risks and recommendation.
