# Changelog

## 2.0.0 — 2026-11-22

- Rebranded the system **AgentCollab** and standardized every skill/command on the `agent-collab` namespace.
- Reworked command names so every slash command begins `/agent-collab`.
- Made `/agent-collab` the universal router; domain commands are optional shortcuts.
- Defined `/agent-collab-swarm` as same-model internal peer review using separate execution contexts, not task delegation or a substitute domain team.
- Added a clear distinction between internal swarm, external model collaboration, single-agent perspectives, challenge, paths and audit.
- Strengthened independence protocol: neutral common brief, private locked first submissions, coordinated cross-examination, evidence verification, participant reassessment and evidence-led adjudication.
- Added runtime capability and honesty requirements: do not claim sessions, isolation, model identity, transport or verification unless observed.
- Added explicit no-majority-vote, no-forced-disagreement, no-forced-consensus and bounded-iteration rules.
- Added installation safeguards for auditing existing skills, agent frameworks, commands, MCP/A2A integrations and permissions before changes.
- Corrected shared reference/template paths so they resolve when skills are installed as sibling folders.
- Added acceptance tests, evaluation measures and domain shortcut guidance.

## 1.0.0 — 2026-11-22

- Initial collaboration and perspective system.
