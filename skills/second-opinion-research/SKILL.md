# /second-opinion-research — Research Shortcut

## Purpose

Apply a rigorous research method to the task. This is a domain shortcut, not a separate research-agent team. Use the universal `/second-opinion` router if the collaboration topology is not specified.

## Method

1. Define the question, scope, time window and exact claims to investigate.
2. Establish source hierarchy and what counts as reliable evidence for this subject.
3. Identify primary/authoritative sources, standards, original studies, official docs or first-party data.
4. Check recency, versions, publication dates and whether a source actually supports the claim.
5. Seek counter-evidence and competing interpretations.
6. Track source provenance and do not double-count copies of the same origin.
7. Separate facts, interpretation, assumptions and unknowns.
8. Verify high-impact claims using primary sources or reproducible checks where possible.
9. Synthesize only to the degree supported by the evidence.

## Collaboration guidance

For internal swarm, every participant receives the same core research question and common evidence pack. Do not automatically assign different source silos in the independent first pass. Use targeted source verification after independent conclusions are preserved. For external reviews, send the same neutral brief and track actual source access.

## Report

Include research question, scope, principal findings, source quality/provenance, counter-evidence, claim status, date/version limitations and open questions. Cite material factual claims with source references available in the host.
